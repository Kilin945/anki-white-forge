# 全牌組品質標準（使用者已審核）

日期：2026-07-05
狀態：**已核准**——使用者審過本標準後全權下放執行，至結案報告前不再介入。
性質：一次性全牌組整治的驗收契約（811 張，My_Daily_English）。未來生成閘（另案）沿用同標準。

## 權責鏈

使用者（訂方向、審本標準、收結案報告）→ Claude 主控（標準持有者、QC、裁定）→ 16 個並行 auditor agents（只查＋提案，經主控核准後直接寫入）。

## A. 每張卡 PASS 條件

| # | 項目 | 標準 |
|---|---|---|
| S1 | 句子存在 | 非空、非佔位符 |
| S2 | 含目標字 | 句中出現目標字。容忍：規則變化（-s/-ed/-ing）、不規則動詞（sweep→swept）、片語分離與變位、**句中大小寫**（句首大寫合法）、連字號差異。完全不出現 = FAIL |
| S3 | 長度 5–16 字（目標 6-12）| >16 字 FAIL；<5 字 FAIL |
| S4 | 非定義句 | 禁 "X means..." / "X is a kind of..." / 詞典腔 |
| S5 | 文法與自然度 | 文法正確、自然、單一具體情境、無亂碼/HTML 殘留 |
| S6 | 單字翻譯 | 繁中 1–6 字（或合法英文專名保留）、與句中用法同義、禁同義詞並列 |
| S7 | 整句翻譯 | 完整繁中、語意等價、專名保留原文 |
| S8 | 六欄俱全 | Sentence/Sentence_CN/Translation/Audio/Front_Audio/Image 非空（Image 只驗存在） |
| S9 | Front 合法 | 真實英文字/片語、無拼錯、無 HTML entity 殘留、**必須全小寫**（全大寫縮寫如 ASAP 例外——沿用 normalize_fronts 慣例）|
| S10 | 句音同步 | 句子被改寫的卡，音檔必重生（構造保證）|

語意選擇：Association → SWE 領域義 → 日常義；無 Association 的多義字按此判合理即 PASS。

## B. FAIL 修改規則

| FAIL | 動作 |
|---|---|
| S2–S5 句子類 | 重寫句子（6-12 字、含字、具體情境）＋連動重寫 Sentence_CN ＋檢查 Translation 仍符新句（不符一併改）＋標記重生 Audio |
| S6/S7 翻譯類 | 只改該翻譯欄 |
| S8 缺欄 | 文字欄 agent 補寫；音/圖走既有工具 |
| S9 Front 髒 | 明顯筆誤→主控裁定改拼法＋全欄重生（大小寫違規→轉小寫，欄位內容不重生）；無法判定原意→不動、列結案報告 |

## C. 已簽核例外（修完仍存在的狀況）

1. 詞形變化算 PASS（不強制原形）
2. 無 Association 多義字的語意選擇按優先序，可能非使用者原意（無解，靠日後複習標記）
3. 圖片內容不在本輪（只驗存在）
4. 音檔採構造保證，不逐一聽（使用者抽聽）
5. 翻譯選詞微差算 PASS（意思錯才 FAIL）

## D. 流程

```

Phase 2  主控 QC:①全量機械複驗提案(含字/長度/非定義/中文格式,程式檢查 100%)

```
